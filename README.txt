【設置方法】
1. このフォルダの中身をすべて、HTTPSで公開できる静的ホスティング(Cloudflare Pages / Netlify / GitHub Pages など)に置きます。
2. 各端末で、一度だけネットに接続して index.html のURLを開きます。
3. iPhone/iPad: Safariの共有ボタン→「ホーム画面に追加」。パソコン: Chrome/Edgeのインストールボタン。
4. 以降は圏外でも、ホーム画面のアイコンから開けます。
【更新】 ファイルを差し替えるときは、sw.js の先頭の nutri-v1 を nutri-v2 のように変えてください。
